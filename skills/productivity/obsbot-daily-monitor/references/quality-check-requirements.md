# 视频质检要求（来自 IMA 笔记 OBSBOT每日上线SOP）

## 视频内容检查

### 原画直出
- 是否包含原画直出演示

### 特殊主题判断
以下主题需要特殊标记：
- 榜单/对比
- OBS 教程
- 多机搭建
- 特殊使用场景（播客/体育/直播/远程医疗等）
- 展会/采访

### 内容分类规则
- **常规产品测评/工作流展示/desk setup/小工具推荐** → 不用特殊标记
- **非合作性质视频**（博主自发测评）→ 根据博主体量大小/视频内容价值自行判断
- **展会/采访等特殊活动视频** → 需要标记

## 描述区检查（每项打勾或打叉）

### 链接检查
- ☑️/☒ 官网链接（obsbot.com）
- ☑️/☒ 亚马逊链接（amazon.com/.de/.co.jp 等）
- ☑️/☒ 渠道链接（经销商网站，如 pqs.com.tw）
- ☑️/☒ 短链（不确定是否正确时点开查看）

### 信息检查
- ☑️/☒ 标签（#obsbot、#obsbot_tiny3lite 等，1-2 个标签也算符合）
- ☑️/☒ 折扣信息（折扣码、affiliate 链接等）

## 打分格式

每条符合 SOP 要求的视频必须包含两部分质检：

```
- 视频内容质检：
  - ☑️/☒ 常规产品测评
  - ☑️/☒ 原画直出演示
  - ☑️/☒ 特殊主题：XXX（如有）
- 描述区质检：
  - ☑️/☒ 官网链接：有/无
  - ☑️/☒ 亚马逊链接：有/无
  - ☑️/☒ 折扣信息：有/无（如有，写明折扣码）
  - ☑️/☒ 标签：有/无（如有，列出主要标签）
```

## 排除标准

以下视频应排除出 Part 2：
- 只挂购买链接未在视频内展示产品
- 纯官方宣传素材切片
- 品牌大使直播中使用（非专门产品测评）
- 仅描述中提到使用 OBSBOT 但无产品展示
- 骑行/游戏等直播中使用摄像头但无产品介绍
