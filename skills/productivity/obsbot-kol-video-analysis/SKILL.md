## 一、章节标题格式

```
视频N：<类型>
```
类型是固定枚举，不要自创：

| 类型 | 适用视频 |
|---|---|
| 深度测评 | 单品全面评测 |
| 对比 / 对比测评 | 与竞品横向对比 |
| 榜单 | 多款产品盘点排名 |
| 教程 / 多机搭建教程 | 教学、搭建流程 |
| 桌搭 | 桌面场景展示短片 |
| 直播垂类测评 | 直播博主做的评测 |
| 游戏直播场景 | 游戏场景切入 |
| 会议场景 | 会议场景切入 |

## 二、基本信息区（✅ 开头，勾号后**不加空格**）

```
✅视频链接：https://www.youtube.com/watch?v=xxx
✅视频标题：英文原标题 或 中文翻译（原标题）
✅博主类型：livestream 尾部博主        ← 可选
✅红人类型：科技数码/居家办公/生产力测评类博主   ← 可选
```

## 三、✅视频亮点（核心板块，必须写）

**一段总括 + 若干"•"要点**，总括说明：视频形式 + 内容覆盖范围 + 红人态度倾向。

要点要写「为什么这条视频对营销有价值」，不是复述视频。参考真实写法：

```
✅视频亮点：该视频为四机横向对比评测，核心不是"谁更清晰"，而是将PTZ webcam和固定webcam
放到不同场景里，比较做工、体积与安装灵活性、白平衡与肤色、对焦速度与稳定性……
• 四分屏对比直观，专业度强：达人在每个测试场景中先使用四分屏同步展示4款画面，
  让观众第一时间看出差异，随后再展开逐项讲解。这种先总览、再细拆的方式，
  既提升信息传达效率，也增强了对比说服力。
• 强对比凸显产品优势：以万元高端专业设备为参照物，直观凸显 OBSBOT Tiny 3
  低成本、易搭建、高画质三大优势，说服力极强。
• 植入策略优秀：先证明Tiny 3是目前webcam天花板，然后证明竞品Insta360软件生态难用，
  最后拿出基础款Meet 2，告诉粉丝入门款都比竞品好用——比单推一个产品更让观众信服。
```

## 四、⛔ 必写：红人的产品优缺点评价（最容易漏）

产品团队要看红人对产品的优缺点分析。**每份报告都必须有这一块**，用以下任一种形式：

**形式A（单品测评）— 独立章节**
```
五、缺点分析
博主很坦诚地列出了几个缺点：
• 价格：$349美元（约130万哥伦比亚比索），博主表示很多人可能买不起。
• 需要好光照：低光环境下画质会打折扣。
• 重启不记忆位置：关机再开机，云台会回到默认位置，不会记住上次在哪。
• 内置麦克风一般：博主表示摄像头就是摄像头，麦克风不是它的强项，想收音好还是得外接。
• 部分功能需要初始配置：不是开箱即用，需要花时间调参数。
```

**形式B（单品）— ✅博主观点 双栏**
```
✅博主观点：
• 积极：Jared Polin 对OBSBOT Tail 2的评价非常积极。他认为这是"极大地降低了高质量现场制作门槛"
  的设备。如果你需兼顾多机位、需要走动演示，但又没预算雇佣多名摄像师，这款相机是很高效的生产力工具。
• 局限性：博主也坦言，绝对画质肯定比不上搭载全画幅/半画幅传感器的大型微单。
  但考虑到便利性和自动化程度，这属于合理的取舍。
```

**形式C（对比/榜单）— 逐产品列优缺点**
```
9. 优缺点总结
Insta360 Link 2 Pro
优点：价格更有竞争力、软件更简洁易用、整体体验均衡
缺点：体积较大、麦克风配置略逊、可调参数相对较少
OBSBOT Tiny 3
优点：更小巧、更隐蔽、更高帧率（1080p120）、三麦+空间音频、软件功能更丰富、可深度调节
缺点：价格明显更高、软件对新手不够友好
```

**形式D（榜单）— 评价分级**
```
博主的测评结果和评价：
• Yolo Cam S3：画质出色，色彩自然，对焦快且准。评价极高，评为最佳静态4K摄像头，
  画质可媲美4000美元专业相机
• OBSBOT Tiny 3：画质优异与Yolo持平，追踪响应快，手势实用，色彩调校自然好看。
  评价极高，被评为最佳自动追踪摄像头，能解决"出画"痛点，也是博主日常主力设备
• Razer Kiyo V2：默认画面糟糕、过度锐化严重。评价较低，不推荐购买，
  $150定价在竞品面前缺乏竞争力。
```

## 五、功能/对比主体（编号 + • 两层）

```
1. 核心硬件与参数
• 画质与传感器： 搭载 1/1.5 英寸 CMOS 传感器，支持最高 4K 60fps。
• 变焦能力： 支持 5倍光学变焦 和额外数字变焦（最高12倍混合变焦）。
  博主特别强调光学变焦的优势，建议尽量使用光变以保证画质。
2. 极其丰富的专业接口（最大亮点）
• 视频输出： 3G-SDI、HDMI 2.0。
• 网络与供电： 全尺寸以太网接口，支持 PoE+，对多机位固定安装非常实用。
```

要点写法：**冒号后跟具体参数/事实，再用一句话点出意义**。不要只写"接口丰富"。

## 六、结论 / 总结（必须以编号列表）

```
结论
博主根据不同的预算和需求给出了最终结论：
1. 不差钱的完美选择：OBSBOT Tiny 3 ($349)，它是全场综合表现最好的设备。
   缺点仅仅是价格最贵以及软件界面稍显笨重。
2. 最具性价比的云台摄像头：Insta360 Link 2 Pro ($250)，性价比极高。
   唯一的缺点是默认画面偏红，需要用户自己花点时间在软件里把红色调低。
```

或

```
总结
1. 主要受众：适合预算相对充足，对webcams的画质有要求的主播及内容创作者
2. 核心价值：突出Tiny3 画质优秀 & 色彩校准自然 & AI追踪 & 非常适合动态场景，
   并直接说明比Insta360好
```

## 七、结论标记（高频，体现人味）

很多条目结尾用 `👉 结论：xxx`，例如：
```
👉 结论：从配置和功能来看：Tiny 3在音频方案上更强、更灵活，实际音质：需用户主观判断（博主未给出绝对胜负）
👉 结论：完全打平
👉 结论：Insta360：更适合追求简单体验用户；Tiny 3：更适合需要深度控制的进阶用户
```

## 八-0、结构与行文硬约束（2026-09-17 用户明确要求，优先级最高）

### 四条固定结构
```
视频：<类型>
✅视频链接 / 视频标题 / 红人类型 / 上线时间 / 视频时长 / 产品价格
✅视频亮点：（只用一个自然段，简短）
一、<内容中生动出色的地方>（按视频播放顺序展开）
二、优缺点（优点 / 缺点 分列）
三、结论
```

### 行文铁律
| 禁止 | 说明 |
|---|---|
| ❌ 破折号 `——` `–` `—` | 正常人聊天不这么写。改用逗号、顿号或直接断句 |
| ❌ 引用英文原话 | 不要抄视频里的英文句子。要引也只引**中文**原话，且短 |
| ❌ ⚠️ 类提醒框 | 不要写"内容属性提醒""注意"这类编者按 |
| ❌ 逐条给结论 | 不要每写一点就 `👉 结论`。**所有结论集中放最后一节** |
| ❌ 顺序跳跃 | 严格按视频里出现的先后顺序写，不要一会儿讲接口一会儿回头讲屏幕 |
| ❌ 视频亮点写成多段 | 视频亮点 = **一个自然段**，3~5句，讲清"什么形式 + 谁做的 + 覆盖了什么 + 红人态度" |

### 优缺点 / 结论 的颗粒度（2026-09-17 用户二次反馈）
- 优缺点**不要逐项罗列十条八条**，按维度归纳成 4 条左右，每条把同一类的细节用分号串起来写。
  - 例：`硬件规格全面顶配。7英寸AMOLED屏幕，800尼特加100,000:1对比度；16路视频源，4路HDMI中2路支持4K/60fps、3个USB口、最多10路IP源支持NDI和SRT；网络是2.5G加Wi-Fi 6加SIM卡；存储是128GB加1TB microSD加外接硬盘。`
- 缺点归纳成 2~3 条即可，可以写"内容覆盖不足"这类内容层面的问题。
- 结论**归纳成 3 条**，每条长度适中（比优缺点每条略长），不要拆成五条。
  - 建议三段式：`主要受众` / `核心价值（含红人判断）` / `素材可用性与跟进建议`
- 通篇编号条目（优缺点加结论）控制在 10 条左右最舒服。

### 四类典型 AI 痕迹（2026-09-17 用户四次反馈，务必逐条自查）

| AI 痕迹 | ❌ 例 | ✅ 改法 |
|---|---|---|
| **抽象运营黑话做小标题** | `1、开场用真实案例做钩子` / `4、力量倍增器与一次采集多用途` | 用朴素名词短语：`1. 开场定位` / `4. 人力和交付效率` / `5. 硬件细节` |
| **元评论句**（先给评价再展开） | `这是全片最核心的论点。博主先让观众想象...` / `博主对硬件讲得比同类视频细，重点放在用得舒服的地方：` | 删掉评价句，直接讲博主做了什么：`他让观众先想想自己办公室有几个人、工资表上有几个人，再讲...` |
| **不是A而是B 对偶句** | `视频一上来不是讲参数，而是直接展示...` | 改成直接陈述：`开场没有讲参数，直接放了一段...` |
| **总评句 / 抽象概括句**（最容易漏） | `他讲得比同类视频细，落点都在用得顺手的地方。` / `他把 OBSBOT 的竞争力归到整套生态上。` / `商业价值讲得明白：` / `条件对设备不太友好。` | **整句删掉**，直接从事实写起：`全铝机身，四角有凸起可以保护屏幕...` / `OBSBOT 从初代 Talent、Tail Air、Tiny 3 Titan 到无线麦克风都有对应产品...` / `商业价值：减少人力依赖、一次采集多用途` |
| **带褒义的评价动词** | `主动披露` / `坦诚说明` / `客观指出` / `着重强调` | 换中性词：`说明` / `提到` / `说` |
| **过度分点** | 通篇 1. 2. 3. 4. 5.，每条都是短句罗列 | 内容部分用小标题加连贯段落；只有优缺点和结论才用编号 |

**自检命令**：写完搜一遍 `不是`、`而是`、`这是全片`、`最核心的论点`、`做钩子`、`值得注意`、`重点放在`，命中就改。

**写内容部分的要点**：小标题用两到四个字的名词短语，正文按"博主做了什么 + 说了什么 + 具体数字"往下写，不插入自己的评价和总结。

### 优缺点 / 结论 的写法（2026-09-17 用户三次反馈：AI味重）

**核心问题**：写成了完整论述句 + 公文腔引导词 + 解释性尾巴。文档里的写法是**短词组堆叠**。

| ❌ AI味写法 | ✅ 文档写法 |
|---|---|
| 一体化程度高。可以替代笔记本、导播台、编码器、录像机和监视器，不需要外接电脑就能独立运行，这是博主最认可的核心卖点。 | 一体化程度高：替代笔记本、导播台、编码器、录像机、监视器，不接电脑也能独立运行 |
| 硬件规格全面顶配。7英寸屏、16路信号源、2.5G网口、128GB存储，接口和网络都做到了专业级别。 | 规格全面顶配：7英寸AMOLED（800尼特、100,000:1）、16路信号源（4路HDMI含2路4K60、3个USB口、10路IP源）、2.5G网口加Wi-Fi 6加SIM卡、128GB内置加1TB microSD |
| 核心价值：约$2,999的价位实现一台设备替代笔记本、导播台、编码器、录像机和监视器。16路信号源、4K60输入输出……功能完整度在一体机品类里属于顶配。博主整体态度积极，认为相对上一代是重大进步。 | 核心价值：一台设备替代笔记本 & 导播台 & 编码器 & 录像机 & 监视器 + 16路信号源 + 4K60输入输出 + 2.5G网口/Wi-Fi 6/5G三路上网 + 双热插拔电池 + ISO四路独立录制。博主认为相对上一代是重大进步。 |

**规则**：
1. 优缺点每条 = `短语标签：顿号分隔的关键词罗列`，**不写完整句，不加"这是最核心的卖点""留了空间""都做到了专业级别"这类评价尾巴**
2. 结论里的能力/卖点用 `&` 和 `+` 串联关键词，不要写成完整论述句
3. 结论标签可以用带评价色彩的短语，如「不差钱的完美选择」「最具性价比的云台摄像头」，比「主要受众：」这种公文腔更有人味
4. 缺点可以短到 `讲得多、讲得浅：控制方式和快捷键只罗列不演示`
5. 结论开头可以加一句定性说明，如「博主给出的是规格层面的判断，没有实战验证，所以这份结论偏产品能力，不偏使用体验。」
6. 整体篇幅：优缺点加结论合计 10 条以内，全文 3200 字左右

## 九、工作流程

1. **取字幕**：`yt-dlp --cookies-from-browser chrome --proxy socks5://127.0.0.1:1082 --remote-components ejs:github --write-auto-subs --sub-lang en --sub-format vtt --skip-download --ignore-no-formats-error -o /tmp/vt_%\(id\)s URL`
   - 若 yt-dlp 报 "RequestBlocked"，改用 `youtube-transcript-api`（需 PySocks + 代理环境变量 `HTTPS_PROXY=socks5h://127.0.0.1:1082`）
2. **取元数据**：`curl -s "https://www.youtube.com/oembed?url=...&format=json"` 拿标题/频道；`yt-dlp --print "%(upload_date)s|%(duration)s|%(view_count)s"` 拿日期/时长/播放量
3. **读字幕全文**，整理出：产品功能点、红人评价、缺点吐槽、场景演示、对比结论
4. **按本规范写 docx**（python-docx），文件名如 `OBSBOT <产品> <红人> KOL视频解析.docx`
5. **自检**：有没有👉结论、有没有红人优缺点、有没有具体数字、有没有AI套话

## 十、常见坑

- 飞书文档的章节是**折叠**的，用浏览器读需要点开 `.fold-wrapper.fold-folded` 里的 `.fold-handler` 才能展开（展开后 scrollHeight 会从 ~5千涨到 ~13万）
- 文档里"红人"和"博主"是同一意思，看上下文选词
- 报告是写给**营销团队**看的，除了内容描述还要有"这条视频能怎么用"的判断
- 视频亮点段落里必须包含红人对产品优缺点的总结评论，不能只列功能
