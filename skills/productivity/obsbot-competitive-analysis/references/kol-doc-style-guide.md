# KOL文档风格分析参考

## 参考文档：KOL & 产品营销视频对接.docx

### 文档结构特点

```
视频1：博主名 & 产品名 - 原视频✔️
✅视频链接：URL
✅视频标题：完整标题
✅视频概述：2-3句话，侧重产品功能和博主态度
✅上线时间：YYYY年M月D日
核心升级（或功能亮点）
├── 功能1：具体描述
├── 功能2：具体描述
└── ...
```

### 语言风格特征

- **Emoji使用**：✅前缀标记关键信息（链接、标题、概述、时间）
- **标点符号**：以中文标点为主（，。：），英文标点用于URL和技术术语
- **常用词汇**：博主、视频、产品、功能、场景、推荐、认可、侧重、讲解、展示、演示
- **语气特点**：专业但有温度，不生硬，类似营销文案
- **避免的表达**：不使用"首先/其次/最后"、"综上所述"、"值得注意的是"

### 视频概述写作模式

```
视频侧重[功能1]/[功能2]/[功能3]几个板块来讲解，重点讲解了[核心功能]，博主对于产品的认可度比较高，在视频中对产品的适用场景推荐涉及到了[场景1]/[场景2]等。
```

### 功能描述写作模式

```
[功能名称]：[技术参数]。[使用效果/用户反馈]。[适用场景]。
```

### 截图建议表格格式

| 时间点 | 截图内容 | 截图目的 |
|--------|----------|----------|

### 总结写作模式

```
这个视频是一个优秀的KOL营销案例，博主通过[方法1]、[方法2]、[方法3]，有效地展示了[产品]在[场景]上的使用价值。视频内容[特点]，能够有效吸引[目标用户群体]。
```
