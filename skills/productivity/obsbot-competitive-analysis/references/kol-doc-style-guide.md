# KOL文档风格分析参考

## 参考文档：KOL & 产品营销视频对接 (1).docx

⚠️ **必须是 (1) 版本**（243MB），不是旧版（218MB）。两个版本的格式有显著差异，(1)版本是当前正确的格式标准。

### 文档结构特点

```
视频：简短标签（如"深度测评""多机播客搭建""竞品横评""对比"）
✅视频链接：URL
✅视频标题：完整标题
✅视频概述：2-3句话，侧重视频讲了什么板块、博主认可度、适用场景
✅上线时间：YYYY年M月D日
✅博主：频道名（博主名）
章节标题（如"核心升级""AI功能""其它亮点功能"）
├── 要点描述：具体内容。使用普通段落排列，不用bullet list
├── 要点描述：具体内容
├── -子要点：用"-"开头的更细节层次
└── ...
总结分析
├── 适用人群：...
├── 核心价值：...
├── 不足：...（如有）
└── 结论：...
```

### 语言风格特征

- **Emoji使用**：✅前缀标记关键信息（链接、标题、概述、时间、博主）
- **标点符号**：以中文标点为主（，。：），英文标点用于URL和技术术语
- **常用词汇**：博主、视频、产品、功能、场景、推荐、认可、侧重、讲解、展示、演示、对比、实拍
- **语气特点**：简洁、专业，像内部工作文档而非AI生成内容
- **避免的表达**：
  - ❌ "首先/其次/最后"、"综上所述"、"值得注意的是"、"不难发现"
  - ❌ "这是一个优秀的..."、"这个视频具有..."、"可谓..."
  - ❌ 过度修饰和AI模板句
  - ❌ bullet list（用普通段落排列）
  - ❌ 对视频形式做过度解读（如实描述即可，不要刻意拔高）

### 视频概述写作模式

```
视频侧重[功能1]/[功能2]/[功能3]几个板块来讲解，重点讲解了[核心功能]，博主对于产品的认可度比较高，在视频中对产品的适用场景推荐涉及到了[场景1]/[场景2]等。
```

### 功能描述写作模式

```
[功能名称]：[技术参数]。[使用效果/用户反馈]。[适用场景]。
```

### 博主优秀之处写作模式

这是文档的核心板块之一，从营销角度分析博主的内容创作手法：

```
1. {手法名称}：{具体描述博主如何操作，以及这种手法的营销效果}
2. {手法名称}：{具体描述}
...
```

常见分析维度：
- **创意形式** — 博主采用了什么独特的呈现方式（如拳击比赛类比、对比评测、实际演示）
- **对比思维** — 是否有竞品对比，如何突出 OBSBOT 优势
- **细节关注** — 博主是否展示了产品细节（手势控制灯光变化、追踪反馈等）
- **场景拓展** — 是否展示了多种使用场景（手持、支架、远距离等）
- **功能完整性** — 是否全面展示了产品功能
- **客观态度** — 是否保持了平衡的对比方式

⚠️ **关键**：分析必须基于视频字幕中的具体内容，不能泛泛而谈。引用博主的原话或具体行为。

### 总结写作模式

必须使用要点形式，不使用大段文字。固定结构：

```
总结分析
适用人群：[目标用户画像]
核心价值：[产品的核心差异化和用户价值]
不足：[客观承认的短板]（如有）
结论：[最终评价，1-2句]
```
