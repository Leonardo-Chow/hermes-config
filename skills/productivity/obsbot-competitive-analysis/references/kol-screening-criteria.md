# KOL 筛选标准（来自 IMA 笔记）

## 业务指标认知

| 维度 | 规则 |
|:-----|:-----|
| **网红ID** | 按频道 Name 录入系统，非 Handle/User name。ID变更需及时填写 |
| **合作数** | 按实际合作的平台数计算。填写了什么平台默认产出对应平台内容。Shorts不计入单独合作数 |
| **上线率** | 实际上线视频数 / 视频合作数量 |
| **曝光量（观看数）** | 近期最新10个视频均播。**近期爆款视频Views不计入均播计算** |

## 资源建联原则

- ✅ **同市场已回复**：资源录入系统3个月未达成合作 → 需和上一个建联人协商
- ✅ **跨市场已回复**：资源录入系统1个月未达成合作 → 自动释放，直接建联
- ✅ **跨市场已合作**：由原对接人跟进
- ✅ **离职人员资源**：对应市场人员按需建联，资源已分配情况除外

## 🚫 不建联情况

1. 断更三个月
2. 频道涉及敏感内容（政治/血腥/暴力）
3. 黑名单资源

数据参考：Noxinfluencer。**避免与社媒资源重复** — 新开发 IG 资源需同时符合 `Followers ≥ 50k` 且 `Views ≥ 5k`，否则视为无效合作投放。

## 投放市场定义

> **按渠道受众国家占比第一** 划分，不考虑红人所在地理位置。
> 数据参考：NoxInfluencer / Easy KOL / 红人后台数据
> 🚫 **禁止跨市场合作资源**（市场借调情况除外）。跨市场合作资源不计入有效合作。

| 市场 | 覆盖区域 |
|:-----|:---------|
| 🌎 **美洲市场** | 美国 / 加拿大 / 墨西哥 |
| 🌍 **欧洲市场** | 欧洲各国（仓库能发货且关税不是超高地区）|
| 🌏 **澳洲市场** | — |

## 视频类型类别

| 平台 | 类别 | 细项 | 定义 |
|:-----|:-----|:-----|:-----|
| YouTube | 长视频 | **YTB Dedicated Video** | 仅聚焦1个产品，核心是"深度解析单品"。KOL内部要求至少5min详细介绍 |
| YouTube | 长视频 | **YTB Comparison** | 至少包含1个竞品，目标呈现差异/优劣势。不主张对比OBSBOT自家产品 |
| YouTube | 长视频 | **YTB Round-up** | 罗列多个产品无结构化对比，如"5款好用的Webcam盘点" |
| YouTube | 长视频 | **YTB Tutorials** | 传递方法/知识为核心，简单提及产品视为普通测评 |
| YouTube | 长视频 | **YTB Integration** | 至少90-120s的产品植入，Pre-roll/Mid-roll |
| YouTube/IG/TT | 短视频 | **YTB Shorts / TT Video / IG Reels** | Shorts≤3min, TT≤60s(内部)或≤3min(导入), IG Reels≤90s(内部)或≤15min(导入) |
| IG/Twitter | 图文 | **IG Post / Tweet** | IG单张/≤20张，Tweet≤280字符 |
| Twitch/Kick | 直播流 | **Twitch/Kick Livestream** | — |

## 网红类型分类规则

> **按渠道内容占比**：渠道主内容 >60% 标为一级类目；副内容 >40% 补充二级类目（限2个）
> ⚠️ **误区**：不以合作内容判定渠道类型

### 一级类目 & 二级类目

| 一级类目 | 二级类目 | 说明 |
|:---------|:---------|:-----|
| **Tech** | Hometech / Gadget Review / VR / 3C / Drone / PC Build | 🚫纯手机/电脑/键盘/鼠标测评不计入有效类型 |
| **Livestream** | Livestream Tips / Device / Tutorial / Scene | 并非"在开直播"，而是内容以直播为主题 |
| **Camera** | Photography / Videography / Filmmaker / Camera Settings | DSLR: Sony/Nikon/Canon/Fujifilm/Blackmagic |
| **Gamer** | Game Streamer / Gear / Recording(FPS) / Recording / Gaming PC / Game Only | Gear含键盘/鼠标/电竞椅/手柄/耳机/显示屏等 |
| **Content Creator** | Productive Tools / Earning / Draw / Art / Music / Dance / Instrument / DIY / Home Mom / Study Vlog / Online Education | 桌面露脸/手部 |
| **Setup** | Desk Setup / Game Setup | Desk=科技感桌搭，Game=游戏风桌搭 |
| **Apple** | Apple Accessories / Apple News | 配件和资讯 |
| **Live Production** | Church / Wedding / DJ / Music / Interview / Podcast / Healthcare / Concert / Education / Cooking / Sports / Equestrian / Construction | 配合Solution页面的特需场景 |
| **Entertainment** | Reaction / Comedy / Spoof / ASMR / Cosplay / Magic / Anime / Commentary | — |
| **Sports** | Billiards / Baseball / Basketball / Soccer / Table Soccer / Tennis / Football / Skateboard / Roller-Skating / Yoga / Fitness / Darts / Golf | — |
| **Social Profession** | Teacher / Player / Coach / Worker / Groups / Club / Organization / Community / Esports Team | 产生于BA/EWC项目 |

- Setup
