## 决策矩阵

### 选择一个产品

| 条件 | 行动 |
|:-----|:-----|
| CPM < -20% | ✅ 优秀 CPM，优先合作 |
| -20% ≤ CPM ≤ +20% | ✅ 良好 CPM，建议合作 |
| CPM > +20% | ⚠️ CPM 偏高，考虑置换或不合作 |

### 选择两个产品

| 条件 | 行动 |
|:-----|:-----|
| CPM 均 < -20% | ✅ 两个产品都优秀 |
| 一个 < -20%，一个在范围内 | ✅ 优先低 CPM 产品 |
| 两个都在 -20% ~ +20% | ✅ 选择 CPM 更低的 |
| 两个都 > +20% | ⚠️ 考虑只合作一个或不合作 |

## 价格计算

### 单产品
```
总成本 = 合作价格 + 产品成本
实际 CPM = (总成本 / 均播) × 1000
CPM 评估 = (实际 CPM - 基准 CPM) / 基准 CPM × 100%
```

### 双产品
```
总成本 = 合作价格 + 产品A成本 + 产品B成本
实际 CPM = (总成本 / 均播) × 1000
```

| 新兴领域 | -10% |

## 每周筛选流程

1. 每周筛选 KOL 并评估 CPM
2. 按品类分组统计预算使用情况
3. 评估溢出率（实际播放/预期播放）
4. 决定是否续约或寻找新 KOL
