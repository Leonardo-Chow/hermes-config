## 合作建议写法（1-2句话）

### 结构模板
```
[博主特点描述]，[合作切入点/契合度]，[合作空间评估]
```

### 常用句式

**正面推荐**：
- 有合作空间
- 可以合作
- 推荐
- 有较好的合作潜力
- 和OBSBOT产品契合度高

**中性评估**：
- 有一定合作空间
- 可以做种草类合作
- 粉丝量适中，播放量一般，可以做小范围合作测试

**负面/有限**：
- 合作空间较小
- 合作价值有限
- 和OBSBOT产品契合度较低
- 粉丝量和播放量较低，合作价值有限

### OBSBOT 产品切入点

| 博主类型 | 切入点 |
|:---------|:-------|
| 桌搭博主 | 好物推荐、桌面摄像头推荐 |
| 直播博主 | 直播设备、多机位监控、AI追踪 |
| 科技测评博主 | 深度测评、横评对比、种草 |
| 摄影博主 | 视频拍摄、AI跟踪功能 |
| 生活Vlog博主 | 追踪跟拍、生活记录 |
| 游戏博主 | 游戏直播、摄像头推荐 |
| Apple博主 | 苹果生态配件、好物推荐 |

### 示例

**Tech 类**：
```
大型科技测评博主，以游戏和科技产品为主，覆盖面广，有较大的合作空间
```

**Setup 类**：
```
创意设计师博主，视频风格简约高级，桌搭和生产力工具推荐，有一定合作空间
```

**Livestream 类**：
```
直播设备垂类博主，专业性强，粉丝量适中，和OBSBOT产品契合度高，有较好的合作潜力
```

**Camera 类**：
```
webcam垂类博主，有合作价值，可做竞品对比
```

**Gamer 类**：
```
游戏设备测评博主，粉丝量和播放量较低，合作价值有限
```

## 关键原则

1. **基于事实**：根据博主真实风格、粉丝量、播放量、互动率综合评估
2. **简洁直接**：不啰嗦，1-2句话说清楚
3. **突出契合度**：提到OBSBOT产品特点（AI追踪、多设备监控等）
4. **区分头部和中腰部**：头部博主（>1M粉丝）合作成本高，中腰部博主性价比更高
5. **注意竞品关系**：品牌官方频道（如KUXIU）不建议合作
