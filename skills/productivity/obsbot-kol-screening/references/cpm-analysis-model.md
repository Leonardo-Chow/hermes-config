## CPM 计算公式

```
合作价格 = (基准CPM × 均播) / 1000
总成本 = 合作价格 + 产品成本
实际CPM = (总成本 / 均播) × 1000
```

**关键洞察**：产品成本是固定值，均播越高 → 产品成本占比越低 → 实际 CPM 越接近基准 CPM。

## 合作决策规则

### 决策流程

```
1. 确定产品类型（Webcam / Camera）
2. 确定 KOL 品类（Tech / Desk Setup / Gamer 等）
3. 获取 KOL 均播数据
4. 计算实际 CPM
5. 对比基准 CPM 决定合作方式
```

### 合作类型判定

| 条件 | 合作类型 | 说明 |
|:-----|:---------|:-----|
| 实际 CPM ≤ 加分 CPM | ✅ 付费合作 | 优秀 CPM，优先合作 |
| 加分 CPM < 实际 CPM ≤ 基准 CPM | ✅ 付费合作 | 良好 CPM，建议合作 |
| 基准 CPM < 实际 CPM ≤ 上线 CPM | ⚠️ 置换/付费 | CPM 偏高，可考虑置换或谈判 |
| 实际 CPM > 上线 CPM | ❌ 仅置换 | CPM 过高，建议仅置换产品 |

## CPM 优化策略

### 选择高播放/低粉丝比 KOL（核心策略）

**核心洞察**：播放量高、粉丝少的 KOL = 高性价比目标。

| 指标 | 计算 | 优先标准 |
|:-----|:-----|:---------|
| **播放/粉丝比** | 均播 / 粉丝数 | ≥ 0.3（30%）为优秀 |
| **互动率** | (点赞+评论) / 播放 | ≥ 3% 为优秀 |
| **粉丝增长** | 近期粉丝增量 | 正增长为佳 |

**为什么优先高播放/低粉丝 KOL：**
1. **CPM 更低** — 均播高 → 产品成本占比低 → 实际 CPM 更接近基准
2. **合作成本更低** — 粉丝少 → 合作报价通常更低
3. **内容质量高** — 高播放/粉丝比说明内容有吸引力，算法推荐好
4. **性价比最优** — 同样预算覆盖更多观众

**NoxInfluencer 搜索策略：**
```
# 优先搜索 avg_view 高但 follower 中等的 KOL
--avg_view_min 10000 --avg_view_max 50000 --follower_min 3000 --follower_max 80000
```

**筛选优先级排序：**
1. 播放/粉丝比 ≥ 0.5 + 均播 ≥ 10K → ⭐⭐⭐ 最高优先
2. 播放/粉丝比 ≥ 0.3 + 均播 ≥ 5K → ⭐⭐ 高优先
3. 播放/粉丝比 ≥ 0.2 + 均播 ≥ 3K → ⭐ 中等优先
4. 播放/粉丝比 < 0.2 → ⚠️ 低优先（除非品类特别匹配）

### 降低 CPM 的方法

1. **选择高均播 KOL** — 均播越高，产品成本占比越低
2. **优先 Tiny 3 Lite** — 产品成本 $199 vs $349，降低 43%
3. **选择 Desk Setup 品类** — 基准 CPM 最低（$30）
4. **谈判置换** — CPM 超基准时，仅置换产品不支付费用
5. **插播而非专题** — 插播视频基准 CPM 通常更低（Tech $50 vs $60）

### 均播门槛（CPM 达标所需最低均播）

假设使用 Tiny 3 Lite ($199)，基准 CPM 达标所需最低均播：

| 品类 | 基准 CPM | 最低均播 | 计算 |
|:-----|:---------|:---------|:-----|
| Desk Setup | $30 | 6.6K | 199/(30-199/1000)*1000 |
| Content Creator | $37 | 5.4K | 199/(37-199/1000)*1000 |
| Gamer | $50 | 4.0K | 199/(50-199/1000)*1000 |
| Apple | $50 | 4.0K | 同上 |
| Tech | $60 | 3.3K | 199/(60-199/1000)*1000 |
| Livestream | $100 | 2.0K | 199/(100-199/1000)*1000 |

**结论**：使用 Tiny 3 Lite 时，大多数 KOL（均播 > 7K）都能达到基准 CPM。

## 实际案例分析

### 案例 1: Spudd Gaming（Desk Setup，均播 13.7K）

```
产品: Tiny 3 Lite ($199)
品类: Desk Setup
基准 CPM: $30
合作价格 = (30 × 13700) / 1000 = $411
总成本 = $411 + $199 = $610
实际 CPM = (610 / 13700) × 1000 = $44.53
加分 CPM: $24
结论: CPM 偏高（$44.53 > $30），但接近基准，可考虑置换或谈判
```

### 案例 2: TechMishka（Tech，均播 9.7K）

```
产品: Tiny 3 Lite ($199)
品类: Tech
基准 CPM: $60
合作价格 = (60 × 9700) / 1000 = $582
总成本 = $582 + $199 = $781
实际 CPM = (781 / 9700) × 1000 = $80.52
加分 CPM: $48
结论: CPM 过高（$80.52 > $60），建议仅置换
```

### 案例 3: 高均播 KOL（Tech，均播 50K）

```

```
