# Creator Deep Research Workflow（创作者深度调研方法论）

## 适用场景

当需要为**特定产品/活动**寻找合作创作者时使用。与常规 KOL 筛选（NoxInfluencer + YouTube API 自动化）的区别：

| 维度 | 常规筛选 | 深度调研 |
|:-----|:---------|:---------|
| 目标 | 批量发现中腰部KOL | 为特定产品找最佳合作对象 |
| 工具 | NoxInfluencer + YouTube API | Tavily + delegate_task 多平台搜索 |
| 输出 | 腾讯文档smartsheet | Word报告（调研表+合作建议书+创意Brief） |
| 深度 | 频道级（粉丝/互动率/品类） | 内容级（内容分布/TOP3/评论区洞察/合作创意） |

## 四阶段流程

### Phase 1: 调研框架

确定：
- 产品核心卖点（外观/功能/IP联名等）
- 目标受众画像（性别/年龄/兴趣/平台偏好）
- 调研方向（如 Game Gears / Live Streaming）
- 筛选标准（活跃度/粉丝量级/内容相关性）
- 输出模板（调研表字段定义）

**产出**：Word文档，含产品信息、竞品分析、筛选标准、关键词库、搜索策略

### Phase 2: 样本筛选

使用 `delegate_task` 3路并行搜索：

```
Task 1: 方向A搜索（英文平台：YouTube/TikTok/Instagram）
Task 2: 方向B搜索（英文平台）
Task 3: 中文平台搜索（Bilibili/小红书/抖音）
```

每路搜索策略：
- 用 Tavily MCP 搜索多组关键词
- 收集：账号名、平台、主页URL、粉丝数、内容方向、代表内容
- **必须验证URL真实性**（不要编造链接）
- 目标：每方向5-10个账号

**中文平台限制**：小红书和抖音因反爬限制，网页搜索无法获取具体主页。建议：
- 通过APP内部搜索补充
- 使用新榜/蝉妈妈/飞瓜数据等第三方工具
- B站可通过网页搜索获取

**产出**：Word文档，含每个博主的信息卡（平台/链接/粉丝/内容方向/契合度/推荐合作）

### Phase 3: 深度分析

对每个重点博主进行6维度分析：

| 维度 | 分析内容 |
|:-----|:---------|
| 内容类型分布 | 各类型内容占比（Setup Tour/评测/开箱/生活方式/教程等） |
| TOP 3 高播放内容 | 标题、播放量/赞数、链接 |
| 测评关注点 | 博主评测产品时重点关注的方面（颜值?性能?价格?易用性?） |
| 评论区洞察 | 用户最常问/讨论的问题和需求 |
| 个人风格 | 博主的内容调性和美学风格 |
| 合作创意 | 针对该博主的具体内容创意建议 |

搜索策略：
```
对每个博主：
1. 搜索 "博主名 + 平台" 获取详细信息
2. 搜索 "博主名 + review/unboxing" 获取评测内容
3. 浏览博主主页获取最新内容和粉丝数据
```

**产出**：Word文档，含每位博主的详细分析表

### Phase 4: 最终产出

整合前三阶段数据，生成最终报告：

1. **调研总表**：全部博主完整信息（10列：序号/名称/平台/链接/粉丝/内容方向/内容分布/评论区/契合度/推荐合作）
2. **评估矩阵**：5维度评分（内容质量/受众匹配/专业度/互动率/合作意愿）+ 综合评分 + 优先级
3. **合作建议书**：
   - 金字塔策略（头部曝光→腰部种草→尾部口碑）
   - TOP 10 优先合作名单 + 预估费用
   - 分阶段合作计划（预热期→发布期→持续期）
4. **内容策略**：
   - 核心卖点沟通顺序
   - 分平台内容策略（TikTok/IG/YouTube/B站/小红书）
   - 创意Brief模板（每种内容格式一份）
5. **执行计划**：时间线 + 预算参考 + KPI

## Word 文档生成技巧

使用 python-docx 生成格式化报告：

```python
from docx import Document
from docx.shared import Pt, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn

doc = Document()

# 设置中文字体
style = doc.styles['Normal']
style.font.name = 'Microsoft YaHei'
style.element.rPr.rFonts.set(qn('w:eastAsia'), 'Microsoft YaHei')

# 表格样式
table = doc.add_table(rows=N, cols=M)
table.style = 'Light Grid Accent 1'

# 保存
doc.save('/Users/zhoulong/Downloads/文件名.docx')
```

**注意事项**：
- execute_code 沙盒没有 python-docx，需先 `pip install python-docx -q`
- 表格内容用 Pt(7-8) 字号避免溢出
- 链接单独一行方便复制
- 文件保存到 ~/Downloads/

## 评论区用户需求金字塔

从深度分析中总结的通用模式：

```
第一层：购买链接 — "在哪买？"是最高频问题
第二层：价格信息 — "值不值？"、"有平价替代吗？"
第三层：使用体验 — "低光表现怎么样？"、"美颜效果如何？"
第四层：兼容性 — "Mac兼容吗？"、"能用于OBS/Zoom吗？"
第五层：搭配建议 — "怎么和我的桌搭搭配？"
```

## 评估矩阵维度

| 维度 | 1分 | 3分 | 5分 |
|:-----|:----|:----|:----|
| 内容质量 | 画面粗糙、无剪辑 | 中等制作水平 | 专业制作、有个人风格 |
| 受众匹配 | 受众与目标用户无关 | 部分重叠 | 高度匹配 |
| 专业度 | 纯娱乐、无评测 | 有评测但不深入 | 深度评测、有公信力 |
| 互动率 | <1% | 1-3% | >3% |
| 合作意愿 | 无品牌合作经验 | 偶尔合作 | 频繁合作、有MCN |
