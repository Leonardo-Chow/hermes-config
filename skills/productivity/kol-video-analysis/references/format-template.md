# KOL文档格式参考

以下是从 `KOL & 产品营销视频对接 (1).docx` 中提取的格式模板，每次写视频解析时必须严格遵循。

## 示例：视频1 - 深度测评

```
视频1：深度测评

✅视频链接：https://www.youtube.com/watch?v=cP3aXmJpBpU

✅视频标题：OBSBOT Tiny 3 - Voice Tracking | AI-Powered Spatial Audio | The Smallest 4K PTZ Camera Ever!

✅视频概述：视频侧重升级/音频模式/语音追踪/RTC/慢动作/120录制几个板块来讲解，重点讲解了音频模式和RTC，博主对于产品的认可度比较高，在视频中对产品的适用场景推荐涉及到了线上会议/播客/采访等。

✅上线时间：2026年1月28日

核心升级

画质提升：采用了全新的 1/1.28 英寸传感器，光圈达 f/1.8。相比前代，在低光环境下表现更出色，画面更清晰锐利。

视频规格：支持 4K/30fps 录制，并新增了慢动作模式，支持 1080p/120fps。

极其小巧：与iPhone 13 Pro Max比较

AI功能

目标追踪 2.0：可以识别并追踪超过 200 种物体（如宠物、产品等）

手势控制

5种音频模式

Pure Audio Mode：未进行任何处理

Spatial Audio：降噪效果，提供沉浸式录音效果，推荐播客场景。

Smart Omni Mode：适合放在会议桌中心，具备较强的AI 降噪功能；博主通过"开关空调"来呈现降噪的效果

Directional Mode：专门针对采访或电话（Zoom）会议

Dual-Directional Mode

语音追踪 (Voice Tracking)：博主展示了和妻子两个人模拟的播客场景，认为非常适合多人会议或播客场景。

其它亮点功能

远程互动 (RTC)：允许发送一个链接给对方，对方无需安装软件即可通过浏览器远程控制你的摄像头云台

内置提词器：软件端集成了简单的提词器功能，虽然评测者认为还有改进空间，但基础使用没问题
-觉得提词器视图文字不在中心
-无法知道当前字幕的实时位置

总结分析

适用人群：...

核心价值：...

性价比：...

结论：...
```

## 格式要点

1. **标题**：`视频：简短标签`（如"深度测评""多机播客搭建""对比""竞品横评"）
2. **基本信息**：✅开头，每条独立段落
3. **正文**：小标题用加粗，内容用普通段落（不用bullet list）
4. **层级**：子要点用独立段落，更细的点用"-"开头
5. **截图建议**：嵌入正文段落末尾，格式：`(截图建议：MM:SS，描述)`。同一段落多个截图用分号分隔：`(截图建议：12:36，描述1；13:48，描述2)`。不要单独建表格或在文档末尾汇总
6. **总结**：适用人群/核心价值/不足（或性价比）/结论，每个一行
7. **语言**：简洁，用博主原话，不加评论性形容词
