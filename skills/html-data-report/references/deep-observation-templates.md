## 模板 01：地缘/科技/社会大事件（OBS_01_GEO）

**结构锚点**：事件是什么 → 前因后果 → 可能影响 → 未来发展推演

**写作要点**：
- 开篇用粗体标题+一句话定性
- 四段用 `<strong>` 标记小标题，正文用 `<p>` 包裹
- 必须包含具体数据点（价格、时间、机构、百分比）
- 因果链条要显式写出（A导致B，B触发C）
- 未来推演给出 3 个可观测信号+时间窗口
- 字数 500-1000 字（含 HTML 标签约 1000-1300 字符）

**示例（2026-08-25 美伊"经济 D-Day"）**：
```html
<b>美伊"经济 D-Day"：一场没有硝烟的能源豪赌</b>
<p><strong>事件是什么</strong>：2026年8月25日，美国财政部宣布对伊朗实施"史上最大规模金融攻势"制裁包，直指伊朗残存的能源出口与金融生命线。同日，霍尔木兹海峡一艘油轮遭不明投射物击中受损，虽无人伤亡，但这条承担全球约20%海运石油的咽喉首次在制裁生效首日发生实体冲突。伊朗外长阿拉格齐罕见硬核回应："德黑兰已准备好一整套反制预案，美方若升级，伊朗将对等升级。"市场即时反应：黄金刷新三个多月高位（2515美元/盎司），布伦特原油盘中冲高回落，美元指数走弱。</p>
<p><strong>前因后果</strong>：这不是单日突发，而是拜登政府"最大压力2.0"的集中爆发。2024年特朗普重返白宫后，伊核协议(JCPOA)名存实亡，美方转而采用"金融核武器"——切断伊朗央行结算通道、列入FATF黑名单、对第三方买家实施二级制裁。伊朗侧则通过"影子船队"、以物易物、人民币结算维持日均100-130万桶出口（主要流向中国）。此次制裁包新增对伊朗央行行长、国家石油公司实体的全面冻结，并首次明确警告"任何协助伊朗规避制裁的金融机构将失去美元清算权"，直击中国中小银行与离岸结算体系痛点。</p>
<p><strong>可能带来的影响</strong>：① 短期油价波动率飙升，若霍尔木兹再发生一起实体袭击，布伦特恐冲破90美元；② 黄金作为"无对手方风险资产"重新确立避险锚定地位，央行购金潮（中国已连续18个月增持）将获政策性支撑；③ 人民币跨境支付系统(CIPS)使用量可能激增——伊朗被迫加速去美元化，中国买家为规避二级制裁将更多走CIPS+本币结算；④ 美伊若擦枪走火引发区域代理人冲突（胡塞武装、真主党、伊拉克民兵），全球供应链面临"能源+航运"双重冲击。</p>
<p><strong>未来发展推演</strong>：未来4-6周看三个信号——(1)中国大型国有行是否明令停止伊朗能源结算（若停，伊朗出口将骤降40%+）；(2)伊朗是否启动"关闭霍尔木兹"核威慑（需通过IAEA核查浓缩铀库存判断）；(3)沙特/阿联酋增产意愿——OPEC+12月会议若决定增产填补缺口，说明海湾国家已默许制裁生效。对A股而言：石油石化板块(中海油、中石油)短期受益成本端上移，但需警惕需求端衰退预期；黄金股(紫金矿业、山东黄金)逻辑最顺；离岸人民币汇率若因结算需求走强，利好出海板块。</p>
```

## 模板 02：财经宏观深度（OBS_02_FIN）

**结构锚点**：事件是什么 → 前因后果 → 可能影响 → 未来发展推演

**写作要点**：
- 必须结合**国内外双重视角**（A股/美股/汇率/大宗/货币政策）
- 核心逻辑要是"深远影响"而非当日波动
- 当日无重大财经事件时，自动降级为其他类别（科技/产业/政策）
- 引用具体指标：美债收益率曲线、美元指数、ETF流向、央行持仓、利差
- 给出 A 股可操作的板块映射（核心配置/卫星仓/规避雷区）

**示例（2026-08-25 比特币破8万与黄金共振）**：
```html
<b>比特币破8万与黄金创新高：双锚定资产共振背后的货币信用重构</b>
<p><strong>事件是什么</strong>：2026年8月25日，比特币日内突破80,000美元关口，刷新历史高位；现货黄金同步站上2,515美元/盎司，创三个多月新高。同一天，美联储理事沃勒释放"9月降息50基点概率上升"信号，美元指数跌破101，美债收益率曲线陡峭化（2年期-10年期利差从-40bp收窄至-15bp）。更耐人寻味的是：美国现货比特币ETF单日净流入达8.7亿美元（创3月以来新高），而中国央行连续第19个月增持黄金（官方储备超7280万盎司）。两大"非主权锚定资产"在同一日、同方向、同逻辑下共振上涨，罕见地绕开了传统"黄金涨比特币跌"的跷跷板效应。</p>
<p><strong>前因后果</strong>：这不是单纯的风险偏好切换，而是全球货币体系信用锚定的深层裂变。2022年俄乌冲突后，西方冻结俄罗斯3000亿美元外汇储备，打破了"主权债务无风险"的神话；2023-2024年美联储激进加息导致全球美元债务危机（斯里兰卡、加纳、赞比亚相继违约），新兴市场国家意识到持有美债不再是避风港而是风险源。于是出现双重对冲：主权层面——中国、印度、土耳其、波兰等央行疯狂买金（2024年全球央行净买金1136吨，创纪录），去美元化储备；机构/个人层面——比特币ETF获批后，华尔街合规资金合法入场，比特币从"投机筹码"升级为"数字黄金"配置标的。今天的共振，本质是市场对美债长期可持续性的投票——美国联邦债务突破36万亿美元，利息支出超国防开支，财政赤字率常态化6%以上，隐性违约(通胀稀释)成唯一出路。</p>
<p><strong>可能带来的影响</strong>：① 资产配置范式永久改变："60/40股债平衡"失效，机构将被迫配置5-10%黄金/比特币作为尾部风险对冲；② 新兴市场货币面临三难困境——若跟随美联储降息，资本外流压力减轻但输入性通胀上升；若维持高利率，国内经济硬着陆；③ 美元结算体系加速碎片化：金砖国家支付系统、mBridge多边央行数字货币桥、CIPS将承接更多非美元贸易结算；④ 监管套利空间收窄：G20或推动加密资产统一报告标准(CARF)，比特币匿名性边际收益递减。</p>
<p><strong>未来发展推演</strong>：未来3个月看三条线——(1)美联储9月FOMC是否降息50bp（若降，比特币/黄金双双受益流动性宽松；若不降，信用紧缩恐引发风险资产回调）；(2)美国大选结果——特朗普若当选，其承诺"建立国家比特币储备"将成超级催化剂；哈里斯延续现状，监管趋严；(3)中国央行增金节奏——若单月增持超30万盎司，说明去美元化进入加速期。对A股策略：黄金股(紫金矿业、赤峰黄金)作为核心配置；比特币概念股(微策略类标的、矿机厂商)做卫星仓；离岸人民币升值受益板块(出海消电、跨境电商)关注汇率红利；警惕高负债地产/城投债在利率下行未兑现前的违约风险。</p>
```

## 常见坑点

1. **不要写成新闻摘要** —— 深度观察的核心是"透过现象看本质"，要有显式的因果推演
2. **不要只罗列数据** —— 数据要服务于判断，每个数字后要跟"所以什么"
3. **不要用模糊词汇** —— "可能上涨" → "若 X 发生，Y 指标将在 Z 时间窗口突破阈值"
4. **不要重复当日新闻导语** —— 观察要站在更高维度（宏观/结构/博弈）
5. **财经观察当日无料时** —— 必须显式替换（如改为"AI 产业链深度""政策周期研判"等），不可硬凑
